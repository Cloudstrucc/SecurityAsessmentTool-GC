SADD — Security Assessment & Design Documentation

System: ESign Elections Canada

This is a portable end-to-end test fixture standing in for an uploaded Security Assessment & Design Documentation (SADD) artefact. It exists so the document-upload, download, and AI evidence-guidance tests run on any machine without depending on a developer's local filesystem.

Overview

ESign Elections Canada is a Protected B web application for secure electronic signature workflows. It is hosted in Azure (Canada Central) and authenticates users through Entra ID with conditional-access MFA.

Security controls referenced

  • AC-2 Account Management — Entra ID lifecycle and access reviews.
  • SC-8 Transmission Confidentiality — TLS 1.2+ enforced end to end.
  • AU-2 Audit Events — centralized logging to Microsoft Sentinel.

Evidence

Conditional-access policy exports, WAF rule screenshots, and Key Vault access policies are attached to the assessment as supporting evidence.
