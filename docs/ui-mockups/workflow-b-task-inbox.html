Workflow B — “Task Inbox”

Navigation is a work queue, not a site map. You never go looking for a project; the thing that needs you is already in the list on the left, sorted by who is blocked. Picking a task opens a focused work pane with its own mini-wizard, and the ribbon across the top is a live portfolio pipeline — click a stage to filter the queue to it. Use the ribbon or the queue to walk the seven steps.

What this design fixes

  • No hunting. The home screen is “what needs me”, grouped by blocker, with due dates — not a project list you have to interpret.
  • Handoffs are visible. Every task names the next owner, so a sent assessment reads as waiting on Dana, not as a dead end.
  • Portfolio and task in one view. The ribbon shows how many systems sit at each stage; clicking a stage filters the queue.
  • Big jobs become countable sub-tasks. “Review 5 controls” is five items that disappear as you work, instead of one opaque page.
  • Dead ends removed. Finishing a task always writes the next one — to you or to someone else — so nothing ends with “Return home”.
