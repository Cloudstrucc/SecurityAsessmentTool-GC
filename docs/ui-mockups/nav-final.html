Dockable menu — control placement

Default is Top + pinned. Move it, and watch where the pin/position/star cluster lives.
Docked top → the cluster is tucked behind the expander button at the right of the bar; click it to reveal pin / position / set-default.   Docked left or right → the cluster is always visible, pinned to the bottom of the rail.   Pin off → the menu auto-hides; reveal it by moving to the docked edge (it hides again ~2s after you leave).
