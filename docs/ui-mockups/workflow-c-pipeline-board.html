Workflow C — “Pipeline Board”

For people who run many systems at once. Every project is a card; the columns are the seven workflow steps, so the whole portfolio’s position is one glance. A card carries its own progress bar, who it is waiting on, and whether it is overdue. Clicking a card opens a slide-over with that project’s step-by-step lane and a single next action — you do the work without ever losing the board.

Click any card to open its slide-over. The Claims Portal card is the project walked end-to-end.

What this design fixes

  • Portfolio position is free. You see every system’s stage without opening anything — the question “where is X?” disappears.
  • Stalls are obvious. Columns owned by someone else are tinted, and a card that has not moved in N days surfaces an “idle 9 days” chip.
  • Work happens in a slide-over. You never lose your place; close the drawer and the board is exactly where you left it.
  • One lane per project. The drawer shows the same seven steps as the board columns, so the mental model never changes between views.
  • Good for managers and assessors both. The same board answers “what do I do next” (filter to mine) and “how is the programme doing”.
