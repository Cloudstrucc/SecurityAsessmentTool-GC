Workflow usability — three alternatives + one feature concept

Built after running the full intake → assessment → tailoring → assign → evidence → audit → decision workflow end to end on aegis-sa.io. Nothing here is implemented; these are standalone pages for review. Each of the three options covers all seven steps in its own design language — switch steps with the controls at the top of each page.

Three navigation alternatives

Option A

Guided Rail

A persistent rail shows one seven-step journey, who the project is waiting on, and a single “Next action” card with exactly one primary button. A sticky commit bar states what each action will do before you press it.

Best when: users are occasional, run one or two systems, and get lost. Lowest-risk change — it reorganises what already exists.
Open option A →
Option B

Task Inbox

Home is a work queue grouped by blocker, not a project list. Every task names the next owner, big jobs split into countable sub-tasks, and a pipeline ribbon across the top doubles as a portfolio filter.

Best when: several people share a project and handoffs keep stalling. Strongest fix for “I didn’t know it was waiting on me”.
Open option B →
Option C

Pipeline Board

Columns are the seven steps, cards are systems. Idle and overdue cards surface themselves. Clicking a card opens a slide-over with that project’s lane and its one next action, without leaving the board.

Best when: someone runs a portfolio of 10+ systems and needs programme-level answers as well as task-level ones.
Open option C →

A and B are not mutually exclusive: the rail from A can live inside the work pane of B. C is the natural third view (Board / List / Calendar) once either exists.

Feature concept — evidence slots

Interactive

Clickable VALUE / ATTACH slots

Turn every [[VALUE:]] and [[ATTACH:]] placeholder into a clickable slot: a rich-text modal for values, a drop zone for attachments, green when filled, an evidence view that renders values inline and attachments as links, and add/remove of slots. Completeness becomes a real number instead of a guess.

Why it matters: it is the only way to measure how complete a piece of evidence actually is — and it fixes the “0 of 5 · 0%” progress bar that shows while five AI drafts sit on the page.
