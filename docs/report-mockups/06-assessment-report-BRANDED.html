ControlTitle, evidence and assessor finding Result
AC-2(3) Account management — disable inactive accounts
Priority P1 · direct implementation
 Not satisfied
Evidence. Inactive accounts are reviewed quarterly by the service desk using an exported CSV.
Assessor. Automated disablement is not enforced. Sampling of 40 accounts found 6 with no sign-in for 118–204 days still enabled. Quarterly manual review does not satisfy the 90-day requirement.
AU-6(1) Audit record review — automated process integration
Priority P1 · direct implementation
 Partial
Evidence. Application and platform logs ship to a central workspace; three detection rules are active.
Assessor. Correlation is in place for authentication events only. No rules cover privileged configuration change or data-export events.
CM-6 Configuration settings
Priority P1 · direct implementation
 Satisfied
Evidence. Infrastructure defined in Terraform; drift detection runs nightly and opens a ticket on deviation. Baseline documented in CONF-STD-004 rev 3.
Assessor. Verified against pipeline run 2026-07-18 and three prior drift reports. No exceptions.
CP-9 System backup
Priority P1 · direct implementation
 Partial
Evidence. Nightly database backup with 35-day retention; geo-redundant storage enabled.
Assessor. Backups exist and are monitored, but no restoration test has been performed in the current authorization period. Last documented restore: 2025-11-12.
IA-2(1) Multi-factor authentication to privileged accounts
Priority P1 · direct implementation
 Satisfied
Evidence. Conditional Access policy CA-014 enforces phishing-resistant MFA for all privileged roles; report-only mode disabled 2026-04-02.
Assessor. Policy export and 30-day sign-in log sample reviewed. No bypass observed.
PE-3 Physical access control
Inherited — Cloud service provider (SOC 2 Type II, 2026)
 Satisfied
Evidence. Inherited from the hosting provider. Provider attestation reviewed and accepted.
Assessor. Inheritance accepted. Provider report covers the period 2025-10-01 to 2026-09-30.
